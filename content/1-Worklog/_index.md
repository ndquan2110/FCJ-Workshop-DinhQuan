In this worklog, I present the learning and practice process during the First Cloud Journey internship program. Since many labs were completed quickly in a single day, the daily notes have been reorganized into a more balanced 12-week report while still keeping the original learning content intact.

The worklog content includes AWS identity and access management, networking, compute, database, monitoring, cost management, security, automation, storage, container deployment, serverless messaging, the development phase of a student management microservice web app, AWS deployment, CloudFormation, troubleshooting, and the final report summary.

**Week 1:** [Getting started with AWS, IAM, VPC, and EC2](1.1-week1/)

**Week 2:** [RDS, resource tagging, and application deployment foundation](1.2-week2/)

**Week 3:** [Cost guardrails and observability basics](1.3-week3/)

**Week 4:** [DNS, CLI automation, backup, and recovery](1.4-week4/)

**Week 5:** [Security posture, containers, and inter-VPC networking](1.5-week5/)

**Week 6:** [CI/CD, IAM governance, monitoring, systems management, and encryption](1.6-week6/)

**Week 7:** [ Infrastructure as Code, cost analytics, commitment models, FSx, and WAF](1.7-week7/)

**Week 8:** [Advanced IAM, CDK, database migration, and conditional access](1.8-week8/)

**Week 9:** [Exploring CloudWatch, CloudTrail, log, metric, alarm and system monitoring.](1.9-week9/)

**Week 10:** [Exploring AWS Budgets, Cost Explorer, KMS, WAF and cost optimization, system security.](1.10-week10/)

**Week 11:** [Exploring Lambda, API Gateway, Cognito, SQS, SNS and SES in the serverless model.](1.11-week11/)

**Week 12:** [Applying knowledge to the project, deploying a demo on AWS, testing, troubleshooting and finalizing the report.](1.12-week12/)
